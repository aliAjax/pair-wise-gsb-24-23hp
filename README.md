# hxwl-10 考古绘图校核台

遗址探方遗迹单位的平面图 / 剖面图双视图校核与出土物统计。

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- **双视图轮廓**：每处遗迹单位分别保存平面图（闭合多边形）与剖面图（折线）轮廓，附完整修订记录，旧线可在画布上叠加回看
- **联动失效**：一侧视图提交新轮廓后，另一侧自动标记「待复核」，需复核确认或重新绘制后才恢复有效
- **冲突候选线**：两人同时修改同一视图时，基于旧版的后到提交只生成候选线，需逐点处理差异（留当前 / 用候选）后才可采纳合并
- **草稿续作**：绘图点实时暂存 localStorage，保存失败（可开启「模拟保存失败」）或关闭页面后重开，未完成绘图点自动恢复，可继续修改
- **统计闸口**：复核未完成（视图待复核或候选线未处理）的遗迹单位，其出土物不进入统计，并在统计表中标注原因
- 顶部可切换用户模拟多人协作，数据持久化于 localStorage，可随时重置示例数据
