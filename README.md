# hxwl-10 考古探方记录

遗址探方、地层关系与出土物坐标档案 —— 遗迹绘图双视图校核台

## 技术栈

React + Vite + TypeScript + CSS

## 本地运行

```bash
npm install
npm run dev
```

开发端口：5110

## 功能

- **双视图轮廓**：每处遗迹单位分别保存平面图与剖面图的当前轮廓和全部修订记录
- **联动失效**：一侧视图保存后，另一侧自动标记"失效待复核"；复核确认或跟进改绘后恢复有效
- **旧线查看**：修订记录中可回看任意历史版本的轮廓（图上虚线叠加）
- **并发候选线**：两人基于同一版本同时改绘时，后提交的只生成候选线；与当前线逐点比对、逐个裁决差异后才可采纳合并
- **草稿续作**：绘图点实时暂存 localStorage，保存失败（可模拟）或关闭页面后重开，自动恢复未完成的绘图继续改
- **统计口径**：存在待复核视图或未决候选线的遗迹单位，其出土物暂不计入统计

## 协作模拟

- 右上角切换"队员甲 / 队员乙 / 领队"模拟两人同时作业
- 勾选"模拟保存失败"可验证草稿恢复流程：改绘 → 保存失败 → 刷新页面 → 自动恢复续画
